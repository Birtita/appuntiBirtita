01

Struttura di un calcolatore, algoritmi e software

Modello di von Neumann
Quasi tutti i calcolatori seguono questa architettura: una CPU (con ALU per i calcoli e Control Unit per il flusso di controllo, più registri interni velocissimi), una memoria centrale che contiene sia dati che istruzioni (da cui il nome "architettura a programma memorizzato"), e dispositivi di Input/Output, tutti collegati da un bus.
Algoritmo
Sequenza finita e non ambigua di passi elementari che risolve un problema in tempo finito. Deve essere eseguibile, deterministico (o esplicitamente randomizzato) e finito.
Programma
Traduzione di un algoritmo in un linguaggio comprensibile (in ultima analisi) dal calcolatore: dal codice sorgente in un linguaggio ad alto livello, fino al linguaggio macchina (sequenze binarie eseguibili direttamente dalla CPU).
Livelli dei linguaggi di programmazione
LivelloCaratteristiche
Macchinaistruzioni binarie native della CPU, specifiche per architettura
Assemblymnemonici che corrispondono 1:1 alle istruzioni macchina (es. MOV, ADD)
Alto livello (es. C)astrae dai dettagli hardware; serve un compilatore (traduce tutto il programma in anticipo) o un interprete (esegue riga per riga)
Sistema operativo
Software che gestisce le risorse dell'hardware (CPU, memoria, dispositivi) e offre ai programmi un'interfaccia uniforme: gestione dei processi, memoria virtuale, file system, driver di periferica.
02

Logica proposizionale

Una proposizione è un'affermazione che è vera (1) o falsa (0), mai entrambe. La logica booleana studia come combinare proposizioni con gli operatori AND, OR, NOT — esattamente ciò su cui si basa ogni circuito digitale.

Tavole di verità degli operatori fondamentali
ABA AND BA OR BNOT AA XOR B
000010
010111
100101
111100
Leggi di De Morgan
\[ \overline{A \land B} = \overline{A} \lor \overline{B} \qquad\qquad \overline{A \lor B} = \overline{A} \land \overline{B} \]
Negare un AND è come fare l'OR delle negazioni (e viceversa) — fondamentale per semplificare espressioni booleane e condizioni nel codice.
Proprietà utili
Commutativa e associativa per AND/OR; distributiva: \(A\land(B\lor C) = (A\land B)\lor(A\land C)\); elemento neutro: \(A \land 1 = A\), \(A \lor 0 = A\); assorbimento: \(A\land 0=0\), \(A\lor 1=1\); doppia negazione: \(\overline{\overline A}=A\).
03

Codifica binaria dell'informazione

Un calcolatore rappresenta tutto — numeri, testo, immagini, istruzioni — come sequenze di bit (0/1). Cambia solo la convenzione con cui quei bit vengono interpretati.

Numeri interi: binario ed esadecimale

Un numero in base 2 si converte in decimale sommando le potenze di 2 corrispondenti agli 1:

10110101
\[ 10110101_2 = 1{\cdot}2^7+0{\cdot}2^6+1{\cdot}2^5+1{\cdot}2^4+0{\cdot}2^3+1{\cdot}2^2+0{\cdot}2^1+1{\cdot}2^0 = 181_{10} \]

L'esadecimale (base 16, cifre 0–9 e A–F) è comodo perché ogni cifra esadecimale corrisponde esattamente a 4 bit: \(10110101_2 = \mathtt{B5}_{16}\) (\(1011=\mathtt B\), \(0101=\mathtt5\)).

Numeri negativi: complemento a due
Su \(n\) bit, si rappresenta \(-x\) come \(2^n - x\). Il bit più significativo vale come "peso negativo": con 8 bit, il range rappresentabile è \([-128, 127]\). Vantaggio principale: addizione e sottrazione si fanno con lo stesso circuito hardware usato per gli interi senza segno.
Esempio (8 bit)
\(-5\): si parte da \(5 = 00000101_2\), si invertono i bit (\(11111010\)) e si aggiunge 1: \(11111011_2 = -5\). Verifica: \(00000101 + 11111011 = 100000000 \to 00000000\) (il riporto di overflow si scarta).

Numeri reali: standard IEEE 754

Un numero reale si rappresenta in virgola mobile: segno, esponente (con un offset detto bias) e mantissa (cifre significative), analogamente alla notazione scientifica \(\pm 1.m \times 2^{e-\text{bias}}\).

Attenzione alla precisione finita
Solo un numero finito di reali è rappresentabile esattamente: espressioni come 0.1 + 0.2 == 0.3 in C possono risultare false per errori di arrotondamento.

04

Il linguaggio C: tipi e strutture di controllo

Struttura di un programma monomodulo

#include <stdio.h>

int main(void) {
    int x = 5;
    printf("x vale %d\n", x);
    return 0;
}

Le direttive #include importano dichiarazioni (es. printf da stdio.h); l'esecuzione parte sempre da main; return 0 segnala terminazione senza errori al sistema operativo.

Tipi base

TipoDimensione tipicaContenuto
char1 byteun carattere (o un piccolo intero)
int4 byteintero con segno
float4 bytereale, precisione singola
double8 bytereale, precisione doppia
Compatibilità e conversioni
Il C converte automaticamente tra tipi numerici compatibili (conversione implicita, es. int→double in un'espressione mista), ma può far perdere informazione al contrario (double→int tronca la parte decimale). Il cast esplicito (tipo) espressione forza la conversione.

Strutture di controllo condizionali e di selezione

if (n % 2 == 0) {
    printf("pari\n");
} else {
    printf("dispari\n");
}

switch (voto) {
    case 'A': printf("ottimo\n"); break;
    case 'B': printf("buono\n");  break;
    default:  printf("altro\n");
}

Strutture iterative

for (int i = 0; i < n; i++) {
    somma += v[i];
}
int i = 0;
while (i < n) {
    somma += v[i];
    i++;
}

do { ... } while(cond); esegue il corpo almeno una volta prima di verificare la condizione — utile, ad esempio, per la validazione ripetuta di un input.

05

Array, struct e puntatori

Array

int v[5] = {10, 20, 30, 40, 50};
v[2] = 99;   // modifica il terzo elemento

Un array è un blocco di memoria contiguo: gli elementi hanno indici da 0 a n-1, e l'indirizzo dell'elemento i si calcola come indirizzo_base + i * sizeof(tipo).

Struct

struct punto {
    double x;
    double y;
};

struct punto p = {1.0, 2.5};
p.x = 3.0;

Una struct raggruppa campi di tipo anche diverso sotto un unico nome: a differenza dell'array, i campi si accedono per nome (p.x), non per indice.

Puntatori

Definizione
Un puntatore è una variabile che contiene un indirizzo di memoria. &x restituisce l'indirizzo di x; *p ("dereferenziazione") accede al valore puntato da p. 
int x = 42;
int *p = &x;    // p contiene l'indirizzo di x
*p = 100;       // ora x vale 100
Puntatori e array
Il nome di un array usato in un'espressione decade nel puntatore al suo primo elemento: v è equivalente a &v[0], e *(v+i) equivale a v[i] (aritmetica dei puntatori: v+i avanza di i * sizeof(tipo) byte, non di i byte). Per questo un array viene passato a una funzione sempre per indirizzo, mai per copia.
06

Sottoprogrammi e ricorsione

Funzioni e passaggio dei parametri

In C i parametri si passano per valore: la funzione riceve una copia dell'argomento, e non può modificare la variabile originale del chiamante. Per ottenere un effetto "per riferimento" si passa esplicitamente un puntatore:

void incrementa(int *p) {
    (*p)++;         // modifica la variabile del chiamante
}

int main(void) {
    int x = 5;
    incrementa(&x);  // x diventa 6
}
Regole di visibilità (scope)
Le variabili locali a una funzione esistono solo durante la sua esecuzione e sono invisibili all'esterno; le variabili globali sono visibili in tutto il file. Lo sviluppo top-down per raffinamento scompone un problema complesso in sottoproblemi via via più semplici, ciascuno risolto da una funzione.

Ricorsione

Definizione
Una funzione è ricorsiva se richiama se stessa (direttamente o indirettamente). Ogni funzione ricorsiva ben posta ha: un caso base (che termina senza ricorrere) e un caso ricorsivo che riduce il problema avvicinandolo al caso base. 
int fattoriale(int n) {
    if (n == 0) return 1;             // caso base
    return n * fattoriale(n - 1);     // caso ricorsivo
}
Record di attivazione e pila delle chiamate
Ogni chiamata di funzione alloca un record di attivazione (o stack frame) sulla pila (stack): contiene i parametri, le variabili locali e l'indirizzo di ritorno. Alla fine della funzione il record viene "smontato" (pop) e il controllo torna al chiamante. Nella ricorsione, ogni chiamata annidata impila un nuovo record: troppa profondità di ricorsione senza caso base esaurisce lo spazio della pila (stack overflow).
07

Strutture dati dinamiche: liste collegate

A differenza dell'array (dimensione fissa, memoria contigua), una lista collegata è composta da nodi sparsi in memoria, ciascuno dei quali "sa" dove si trova il prossimo: cresce e si riduce dinamicamente durante l'esecuzione.

struct nodo {
    int valore;
    struct nodo *next;   // puntatore al nodo successivo
};

typedef struct nodo Nodo;

Operazioni fondamentali

// scorrere la lista
void stampa(Nodo *testa) {
    for (Nodo *p = testa; p != NULL; p = p->next)
        printf("%d ", p->valore);
}

// inserimento in testa
Nodo* inserisci_in_testa(Nodo *testa, int v) {
    Nodo *nuovo = malloc(sizeof(Nodo));
    nuovo->valore = v;
    nuovo->next = testa;   // il nuovo nodo punta alla vecchia testa
    return nuovo;          // il nuovo nodo diventa la testa
}
Gestione della memoria
Ogni nodo creato con malloc deve essere liberato con free quando non serve più, altrimenti si verifica un memory leak. Attenzione a non dereferenziare un puntatore dopo averlo liberato ("dangling pointer").
08

File

Un file è una struttura dati persistente: a differenza delle variabili in memoria centrale (volatili, perse allo spegnimento), sopravvive alla fine del programma su un supporto di memoria di massa.

ConcettoDescrizione
File di testosequenza di caratteri leggibili (codificati es. ASCII/UTF-8); comodo per interoperabilità, meno efficiente
File binariosequenza di byte "grezzi" nella stessa rappresentazione usata in memoria; più compatto e veloce, non leggibile direttamente
Accesso sequenzialesi legge/scrive dall'inizio in avanti, un dato dopo l'altro
Accesso diretto (random)ci si può posizionare a un offset qualsiasi (es. fseek) senza leggere tutto il resto

Operazioni di base in C

FILE *f = fopen("dati.txt", "r");   // "r" lettura, "w" scrittura, "a" append
if (f == NULL) {
    printf("errore apertura file\n");
    return 1;
}

int x;
while (fscanf(f, "%d", &x) == 1) {
    printf("letto: %d\n", x);
}

fclose(f);
Modalità di apertura più comuni
"r" lettura (il file deve esistere)  ·  "w" scrittura (crea il file, o lo tronca se esiste già)  ·  "a" scrittura in coda  ·  aggiungendo "b" (es. "rb") si apre in modalità binaria invece che testo.
Controllare sempre gli errori
fopen restituisce NULL se l'apertura fallisce (file inesistente, permessi mancanti...): va sempre controllato prima di usare il puntatore al file. Ogni file aperto va chiuso con fclose per garantire che i dati scritti siano effettivamente salvati.
